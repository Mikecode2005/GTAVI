# GTAVI

GTAVI is an independent, fan-made Grand Theft Auto VI information hub with a cinematic landing page, source-aware fact archive, character page, Leonida setting page, media archive, and release countdown.

> **Not affiliated with Rockstar Games or Take-Two Interactive.** This project uses original CSS artwork and links to official sources instead of reproducing game assets.

## Pages

- **Home** — release countdown, confirmed signal, platforms, protagonists, and setting.
- **Intel** — confirmed facts and an explicit rumor firewall for details Rockstar has not officially published.
- **Characters** — Lucia Caminos and Jason Duval, limited to the official public synopsis.
- **Leonida** — an original visual interpretation of the confirmed setting; it is not an official map.
- **Media** — official Rockstar trailers and primary source links.
- **Timeline** — source-aware announcement sequence and current date history.
- **FAQ** — concise answers to platform, setting, release, and official-status questions.
- **About** — editorial policy, research ledger, maintainer contact, and correction path.

## Confirmed facts used

- Current official release date: **November 19, 2026**.
- Current official platforms: **PlayStation 5** and **Xbox Series X|S**.
- Setting: the fictional state of **Leonida**, including **Vice City**.
- Named protagonists: **Lucia Caminos** and **Jason Duval**.
- Trailer 2 footage was captured on PlayStation 5.

The site deliberately does not present a PC date, online-mode details, exact map size, or leaked mechanics as confirmed facts.
