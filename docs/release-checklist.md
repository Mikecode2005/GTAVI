# Release checklist

Before publishing a GTAVI content update:

- [ ] Confirm every new factual claim against a primary Rockstar Games or Take-Two source.
- [ ] Mark superseded dates as historical instead of silently replacing context.
- [ ] Keep rumors and leaks out of confirmed cards.
- [ ] Check the unaffiliated fan-project disclaimer remains visible.
- [ ] Run `node --check public/main.js`.
- [ ] Run `bun run build`.
- [ ] Smoke-test Home, Intel, About, FAQ, and Timeline routes.
- [ ] Update `CHANGELOG.md` when the public experience changes.
