# Contributing to GTAVI

Thanks for helping keep this fan-made hub useful and source-aware.

## Editorial standard

- Prefer Rockstar Games or Take-Two primary sources.
- Include a direct URL for every new confirmed claim.
- Separate confirmed facts, historical announcements, interpretation, and rumors.
- Do not submit leaked game files, unreleased assets, private information, or copyrighted artwork.
- Keep the site independent and clearly unaffiliated with Rockstar Games.

## Code changes

```bash
bun install
bun run build
```

Keep the vanilla architecture dependency-light. Use original CSS artwork or properly licensed assets only. For content changes, update the relevant page and `README.md` source list when the source record changes.

## Pull requests

Explain the source or user-facing reason for the change, include direct links for factual updates, and describe how you verified the build.
