# Security Policy

GTAVI is a static fan-made information site and does not collect accounts, passwords, payment data, or user submissions.

If you find a security issue in the site code or deployment configuration, please contact **femimike2005@gmail.com** with a concise description and reproduction steps. Do not include private credentials or sensitive personal data in a report.

For factual corrections, use the same email or open a discussion through [GitHub](https://github.com/Mikecode2005).
